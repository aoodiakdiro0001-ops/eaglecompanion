# Eagle Companion (رفيق النسر)

لوحة تحكم عربية لإدارة الأجهزة الشخصية والعائلية وأجهزة الفريق الصغير، مبنية على الموافقة الصريحة والشفافية الكاملة. تعرض حالة الجهاز (الاتصال، البطارية، الشبكة، آخر ظهور) وتتيح مشاركة الشاشة لحظياً عندما يبدأها مستخدم الجهاز نفسه.

## المزايا

- تسجيل ودخول بجلسات HttpOnly وكوكي آمن، وكلمات مرور مجزأة بـ `scrypt`.
- مساحات عمل متعددة (شخصية، عائلية، فريق) بأدوار: مالك، عضو، مشاهد.
- اقتران جهاز عبر كود لمرة واحدة صالح 10 دقائق.
- نبضات حالة كل 20 ثانية: البطارية، الشحن، نوع الشبكة، أبعاد الشاشة، آخر ظهور.
- مشاركة شاشة لحظية تبدأ من الجهاز فقط، بعد تأكيد صريح وإذن المتصفح، وتنتهي تلقائياً بعد 10 دقائق.
- الإطارات تُحفظ في ذاكرة الخادم فقط، بصلاحية 5 ثوانٍ، ولا تُكتب على القرص.
- سجل تدقيق لكل الأحداث الحساسة مع ملخص عربي.
- إلغاء وصول أي جهاز فوراً.
- وكيل ويب PWA قابل للتثبيت على الشاشة الرئيسية.
- واجهة RTL داكنة ومتجاوبة.

## التشغيل السريع

المتطلبات: Node.js 20 أو أحدث.

```bash
# تثبيت الاعتماديات
npm install

# نسخ إعدادات البيئة (اختياري للتطوير)
cp .env.example .env.local

# تشغيل خادم التطوير على المنفذ 3000
npm run dev
```

افتح `http://localhost:3000`.

ملاحظات:

- تُستخدم مشاركة الشاشة عبر `getDisplayMedia`، وهي متاحة فقط في سياقات آمنة: `localhost` أو HTTPS.
- يعمل المتصفح على سطح المكتب بشكل كامل. المتصفحات على الجوال لا تدعم مشاركة الشاشة عموماً.
- ملف قاعدة البيانات الافتراضي `data/eagle.db` ويُنشأ تلقائياً.

## متغيرات البيئة

| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `DATABASE_PATH` | `./data/eagle.db` | مسار قاعدة SQLite. استخدم `:memory:` في الاختبارات. |
| `SESSION_SECRET` | قيمة تطويرية | سر HMAC لتجزئة أكواد الاقتران والدعوات. يجب ضبطه في الإنتاج. |

تغيير `SESSION_SECRET` يلغي كل أكواد الاقتران والدعوات غير المستخدمة. لا تضع القيمة الحقيقية في المستودع.

## طريقة الاستخدام

1. أنشئ حساباً من `/register`؛ تُنشأ لك مساحة عمل شخصية تلقائياً.
2. من الصفحة الرئيسية اختر مساحة العمل، ثم «إضافة جهاز» للحصول على كود اقتران.
3. على الجهاز المطلوب، افتح `/pair` وأدخل الكود واسم الجهاز.
4. أبقِ تبويب `/agent` مفتوحاً؛ سيرسل نبضات الحالة كل 20 ثانية.
5. راقب الجهاز من لوحة التحكم. عند الحاجة، اضغط «مشاركة الشاشة» على الجهاز نفسه، أكّد الطلب، ثم اختر الشاشة في نافذة المتصفح.
6. تظهر الشاشة في صفحة الجهاز خلال ثوانٍ، وتنتهي تلقائياً بعد 10 دقائق أو عند الضغط على «إيقاف المشاركة».
7. لإيقاف وصول جهاز نهائياً، استخدم «إلغاء وصول الجهاز» في صفحة الجهاز.

## نموذج الأمان

- كل جهاز يملك رمزاً عشوائياً 32 بايت، يُخزَّن مجزأً بـ SHA-256، ويُرسل كـ `Bearer`.
- جلسات المستخدم مخزنة في قاعدة البيانات، والكوكي `HttpOnly` و`SameSite=Lax`، و`Secure` في الإنتاج.
- تُفحص `Origin` لكل الطلبات المتغيرة المعتمدة على الكوكي لمنع CSRF.
- تحديد معدل للدخول والتسجيل والاقتران وإنشاء الأكواد واستقبال الإطارات.
- الأكواد تُخزَّن كـ HMAC-SHA256 وليست نصاً صريحاً، وتُستهلك مرة واحدة.
- الإطارات تُرفض إذا تجاوزت 400 كيلوبايت أو انتهت جلسة المشاركة أو أُلغي الجهاز.
- رؤوس أمان: `X-Frame-Options: DENY`، `nosniff`، `Referrer-Policy`، و`Permissions-Policy` تمنع الكاميرا والميكروفون والموقع.
- سجل تدقيق لا يتضمن محتوى الشاشة.

### حدود يجب معرفتها

- النسخة الحالية أحادية الخادم: الإطارات وتحديد المعدل في الذاكرة، وقاعدة البيانات SQLite محلية.
- لا توجد مصادقة ثنائية بعد.
- من يملك رمز جهاز يمكنه التظاهر بذلك الجهاز؛ احتفظ بالرمز في المتصفح ولا تشاركه.
- سجل التدقيق يعرض عناوين IP لأعضاء مساحة العمل، وهذا مقصود للشفافية.
- الإنتاج يحتاج HTTPS، و`SESSION_SECRET` قوياً، ونسخاً احتياطياً لملف SQLite، وعكساً عكسياً (reverse proxy) مناسباً.
